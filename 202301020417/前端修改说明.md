# 医生管理页面前端修改说明

## 需要修改的内容

### 1. 移除"用户信息ID"输入框

在新增医生和编辑医生的表单中，需要移除"用户信息ID"（userinfoId）输入框。

**修改位置：**
- 新增医生表单（"新增医生"模态框）
- 编辑医生表单（"编辑医生"模态框）

**需要移除的字段：**
- 标签：`用户信息ID` 或 `User Info ID`
- 对应的输入框元素

### 2. 角色（Role）字段处理

**要求：**
- 角色字段默认值固定为 `"doctor"`（医生）
- 角色字段不允许用户编辑（隐藏或只读）
- 提交数据时，后端会自动将role设置为"doctor"，前端无需传递此字段

**实现方式（二选一）：**

**方式一：隐藏角色字段（推荐）**
```javascript
// 在表单数据中，不显示角色字段，但在提交时自动设置
const formData = {
  // ... 其他字段
  role: 'doctor'  // 固定值，不显示在表单中
};
```

**方式二：显示但只读**
```html
<!-- 如果必须显示，设置为只读 -->
<el-select v-model="form.role" disabled>
  <el-option label="医生" value="doctor"></el-option>
</el-select>
```

### 3. 数据提交格式

提交医生数据时，数据结构应该如下：

```javascript
{
  name: "医生姓名",
  userId: "USER1001",  // 可选
  departmentId: "科室ID",
  title: "职称",
  user: {
    username: "用户名",
    password: "密码",
    email: "邮箱",
    phone: "手机号",
    status: 1,  // 1-启用, 0-禁用
    // role: "doctor"  // 不需要传递，后端会自动设置
  },
  userInfo: {
    realname: "真实姓名",
    gender: 1,  // 1-男, 2-女
    avatar: "头像URL"
    // id: 不需要传递，后端会自动生成
  }
  // userinfoId: 不需要传递，后端会自动从userInfo.id获取
}
```

### 4. 表单验证

确保表单验证规则中：
- **移除** `userinfoId` 的必填验证
- **移除** `role` 的必填验证（如果之前有）

### 5. 编辑时的数据回显

在编辑医生时，从后端获取的数据中：
- **不要回显** `userinfoId` 字段
- **不要回显** `role` 字段（或显示为只读的"医生"）

## 后端已完成的修改

1. ✅ `addDoctor` 方法会自动：
   - 先插入 User（role 自动设置为 "doctor"）
   - 再插入 UserInfo（关联到 User）
   - 最后插入 Doctor（userinfo_id 自动从 UserInfo.id 获取）

2. ✅ `updateDoctor` 方法会自动：
   - 强制将 role 设置为 "doctor"（不允许修改）
   - 更新 User、UserInfo 和 Doctor

3. ✅ 所有操作都在事务中执行，确保数据一致性

## 注意事项

- 用户信息ID（userinfoId）是数据库自增字段，不需要用户输入
- 角色（role）固定为 "doctor"，不允许修改
- 后端会自动处理 User、UserInfo 和 Doctor 之间的关联关系
